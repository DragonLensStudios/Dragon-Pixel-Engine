# Open-Source and Commercial Sustainability Guide

Dragon Pixel Engine remains genuinely open source.

## Public project requirements

- Product-first README.
- Clear build instructions.
- Contribution guide.
- Code of conduct.
- Security policy.
- Support policy.
- Roadmap and known limitations.
- Bounded issues for contributors.
- Honest platform and adapter status.

## Revenue model

Revenue should come from:

- Architecture reviews.
- MonoGame and KNI integration work.
- Qt/C++ editor tooling.
- C#/.NET runtime integration.
- Migration assessments.
- Custom importers and components.
- Build and publishing support.
- Training and workshops.
- Templates and starter projects.
- Priority support.
- Sponsorship.
- Hosted convenience services.

Do not intentionally cripple the open core merely to manufacture a paid feature boundary.
